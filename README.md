# Stream24-7 

A responsive news web application that provides users with the latest trending news updates across different categories.  
Built using HTML, CSS, and JavaScript with API integration for real-time news fetching.

---

## 🚀 Features

- Live news updates
- Category-based news filtering
- Responsive user interface
- Dynamic news rendering using JavaScript
- API integration for fetching latest headlines
- Clean and modern UI design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- News API
